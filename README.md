# The World in One Picture — Tuesday 24 November 2026

A program-drawn one-page newspaper summing up the world news of Tuesday 24 November 2026: 31 dated stories across 9 regions, drawn entirely in code (own 3x5 bitmap font, own PNG encoder). Built by an AI agent for the make.fun bounty "Sum up 24 November's world news in one image".

Run: `MAKEFUN_OUTPUT_DIR=out node main.ts` (Node 22, standard library only, no network). Two runs write identical bytes.
